## 규칙 (WIN/LOSS 실측 차이 순, 10개)

1. [분기] **독자가 자기 글자를 찾아 읽는 구조를 넣는다.** WIN 일간·일지 분기 6.4줄 / LOSS 0.0 (∞).
   `'일간'+'일지' 등장` WIN 5.4회 / LOSS 0회. **이게 단일 최대 변수다.**
   일간 10종·일지 12종·오행 5종·십신 중 하나로 갈래를 치고, 각 갈래에 `: 해설` 을 붙인다.
   갈래 없는 일반론 글은 그 자체로 LOSS 신호다.
2. [해설] 콜론 해설 줄 WIN 3.4 / LOSS 0.0 (∞). `항목` 다음 줄에 `: 한 줄 해설`. 번호만 나열 금지.
3. [마무리] **만세력·전체사주 안내로 닫는다.** WIN 70% / LOSS 0%. 마지막줄 사실종결 WIN 60% / LOSS 0%.
   `내 일지는 만세력 생일 줄 아래 글자` / `상대 사주까지 봐야 나옴` 류 한 줄.
   한정 조항 자체도 WIN 60% / LOSS 20% (3.0배) — 면책이 아니라 **성과 요인**이다.
   마지막 문장이 명언·대구·경구로 읽히면 폐기. 잘 쓴 마무리가 곧 AI 티다.
4. [훅] **첫 줄은 `<꺾쇠 제목>` 으로 고정한다.** (2026-08-27 사용자 결정)
   훅 문구(`단언컨대 ~`, `저녁부터 촉이 ~`, `이 글 본 거? 우연 아냐`, 장면 묘사)는
   버리지 말고 **2행으로 내려서** 제목과 함께 쓴다.
   ⚠ 실측은 이 규칙을 지지하지 않는다 — 성숙 코호트 49건에서 꺾쇠 25건 평균 1,038 / 중앙 249,
   완결 문장 훅 13건 평균 1,401 / **중앙 977**. 꺾쇠는 1위 글(9,613)을 낸 대신 편차가 크다.
   시간대 교란(꺾쇠가 17시·23시에 몰림)도 안 걷혔다. 다음 sync 때 재검증할 것.
   **버려야 하는 건 꺾쇠가 아니라 조각 훅이다** — 아래 하한 참조. 최소 13자.
   첫줄 12자 이하(절단 조각) LOSS 50% / WIN 10% — **0.2배, 최악의 단일 패턴.**
   `헤어지고 나서` / `연락이 뜸해진 게` / `다시 만났는데` 식으로 첫 줄을 잘라 던지는 형식은 폐기.
   (2026-08-26 lr-022~031 배치 전체가 이 형식이었고 10건 평균 189 views 로 전멸)
   꺾쇠 제목 WIN 40% / LOSS 10%. 인사·서론은 0건 — 첫 줄이 곧 제목이다.
5. [구체성] 숫자 포함 WIN 90% / LOSS 30% (3.0배). 연도·월·시 명시 WIN 20% / LOSS 0%.
   띠·시주는 연도/시간 병기 — `돼지띠(1995 1983 1971)`, `축시(1~3시)`. 모호한 시기 표현 금지.
6. [시의성] 시의성 어휘(올해·내년·이번 달·명절·`N월`) WIN 40% / LOSS 10% (4.0배).
   월건·절기·명절을 근거로 깔면 "지금 나한테 해당되는 글"이 된다.
7. [길이] **300~450자.** WIN 평균 369자 / LOSS 170자 (2.2배). 줄수 WIN 14.3 / LOSS 9.3.
   300자 미만은 대개 분기가 모자란다는 신호다. 상한은 500자(Threads API).
8. [줄바꿈] 구절 단위 개행. WIN 평균 줄길이 19자. 4줄 이상 붙은 문단 금지.
9. [단언] 본문은 확정 화법. 헤지 금지, 한정 조항은 마지막 1곳만(규칙 3과 같은 자리).
10. [이모지·어휘] 이모지 글당 0~2개, 훅 끝 또는 CTA 줄만 (WIN 평균 0.1개 — 사실상 안 씀).
    밈 어휘 글당 1~3개(기 빨림·떡상·ㄱㄱ·멱살). 격식 강의체 금지.
