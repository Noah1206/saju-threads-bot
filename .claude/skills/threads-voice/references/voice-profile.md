## 레지스터 — 압축체 고정 (v2 결정)

**~함 / ~임 / ~됨 / 명사종결.** 존대체·반말 구어·칼럼체 사용 금지.

- 근거: 존대체는 사주 계정 디폴트라 피드에서 묻힘. 압축체는 코퍼스 37%(클러스터 I 5건 + A 1건 + F 변형)로 few-shots 확보 가능하면서 사주 판에서 가장 덜 흔함.
- 예외 없음. 존대체 few-shots(02, 16, 20 등)에서 가져올 수 있는 건 **구조뿐**, 문체 이식 금지.
- 압축체 내 변형 스펙트럼: 기본형(~함/~임: 01,07,13,14) / 서술형 어미 혼합(~한다/~된다 가끔: 12,14) / ~셈 명령형(11 — F 클러스터 전용, 규칙 아님).
